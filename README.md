# FinanTienda
Proyecto tecnológico: FinanTienda — Sistema de gestión financiera para tenderos.

## Estructura del repositorio (sugerida)
- `main` (rama principal): contiene la versión final de los documentos y prototipos validados.
- `planificacion` (rama): fase de planificación — incluye el documento `docs/Actividad 1 - Identificar el proyecto tecnológico a trabajar.docx`.
- `prototipo` (rama): prototipos de Figma, imágenes y flujos.
- `design-thinking` (rama): evidencias de empatizar, definir e idear (Miro, notas, entrevistas).
- `riesgos-stakeholders` (rama): matriz de riesgos y mapa de stakeholders.

## Contenido del ZIP
- `docs/Actividad 1 - Identificar el proyecto tecnológico a trabajar.docx` — documento de planificación (fase entregada).
- `docs/imagenes_referenciales.md` — lista de imágenes referenciales de Shutterstock.
- `tools/miro_link.txt` — ejemplo de enlace al tablero Miro.
- `tools/figma_link.txt` — ejemplo de enlace al prototipo Figma.
- `entregables/` — carpeta para subir prototipos, capturas y evidencias.
- `guia_git_subida.md` — guía rápida para subir ramas y archivos desde local.
- `.gitignore` — ejemplo para proyectos con documentos y prototipos.

## Cómo usar este repositorio
1. Clona el repositorio: `git clone https://github.com/tuusuario/FinanTienda.git`
2. Crea y sube ramas según la fase: `git checkout -b planificacion` -> agrega `docs/Actividad 1 - Identificar el proyecto tecnológico a trabajar.docx` -> `git push origin planificacion`
3. Abre Pull Requests desde las ramas hacia `main` para integrar cambios.
